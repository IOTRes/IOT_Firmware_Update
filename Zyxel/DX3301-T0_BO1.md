# Buffer  Overflow Vulnerability in Firmware Update Process of Zyxel DX3301-T0

## Affected Product
DX3301-T0 (firmware version:5.50(ABVY.1)C0)

## Overview

During the firmware update process, there is a buffer overflow vulnerability in function sub_400EE8() of program fwwatcher. When the directory /var/fw does not exist, fwwatcher invokes sub_400EE8() to create the directory and stores the directory path into a buffer v23 with 4096 bytes. However, the path is propagated into buffer v22 with 128 bytes and there is no verification or constraint on the path. Once the hackers control the path and construct a path grater than 128 bytes, a buffer overflow vulnerability occurs, which could cause denial of service.
