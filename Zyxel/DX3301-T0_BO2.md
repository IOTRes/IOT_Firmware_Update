# Buffer  Overflow Vulnerability in Firmware Update Process of Zyxel DX3301-T0

## Affected Product
DX3301-T0 (firmware version:5.50(ABVY.1)C0)

## Overview

During the firmware update process, there is a buffer overflow vulnerability in function sub_40F8EC() of program zhttpd. Function sub_40F8EC() allocates a buffer with 4108 bytes to store the certificate which is obtained through fgets(). Although, there is size limitation in fgets(), the total size of the certificate is unlimited. Function sub_40F8EC() only verifies the flags, such as BEGAIN CERTIFICATE, to determine whether the certificate obtaining should continue. Once the hackers control the certificate and construct a certificate greater than 4108 bytes, a buffer overflow vulnerability occurs.
