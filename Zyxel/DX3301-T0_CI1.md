# Command Injection Vulnerability in Firmware Update Process of Zyxel DX3301-T0

## Affected Product
DX3301-T0 (firmware version:5.50(ABVY.1)C0)

## Overview

During the firmware update process, there is a command injection vulnerability in function sub_411A90() of program zhttpd. Function sub_411A90() directly propagates the return value(v8) of HTTP multipart object into the system command(v10). Once the hackers control v8, they could inject malicious command into the system command.
