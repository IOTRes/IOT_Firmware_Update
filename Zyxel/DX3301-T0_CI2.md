
# Command Injection Vulnerability in Firmware Update Process of Zyxel DX3301-T0

## Affected Product
DX3301-T0 (firmware version:5.50(ABVY.1)C0)

## Overview

During the firmware update process, there is a command injection vulnerability in function sub_4014F0() of program fwwatcher. Function sub_4014F0() 
set the /var/fw permission to 777, which makes the hackers could create a malicious firmware where the firmware name is injected malicious command. And there is no verification on the firmware name, which makes the malicious command could be injected into system command and be executed.
